# Changelog

## 2026-08-16 — Public architecture baseline

- Rebased the public disclosure around field-to-form context architecture.
- Removed the synthetic proof-case requirement.
- Established existing-evidence-only disclosure.
- Canonicalized the public repository as luahelenammc/Moon-Source.
- Migrated the three existing public portables into one public family.
- Retained MSL 4.3 after a major-version audit: new capabilities belong primarily to jurisdiction, procedures, bridges and transport.
- Added a public boundary, evidence classes, terminology and versioning contract.
- Preserved the website as a convenience surface rather than a competing semantic source.
- No repository-wide open-source license was ratified in this baseline.

## 2026-08-17 — Post-launch hardening

- Restored a compact public proof map while keeping the README oriented around concrete uses and deeper linked documentation.
- Recorded the promoted production surface as the active website state and kept repository, portable, MSL and website versions distinct.
- Repaired fragment-aware Markdown link validation and semantic portable metadata validation.
- Added local repository validation and a separate scheduled/manual mirror-drift check to GitHub Actions.
- Clarified public-boundary, attribution and reuse language without ratifying a repository-wide license.
- Refreshed the Chat–Work product calibration against current official OpenAI documentation; the routing doctrine and MSL 4.3 decision remain unchanged.

## 2026-08-17 — Credits and attribution operations

- Added the bounded public [Credits & Attribution Ops Protocol](docs/CREDITS_ATTRIBUTION_OPS.md) as a Moon Source governance component.
- Connected authorship, provenance, adaptation, permission scope, mirror identity and generated-output credit to the public architecture, procedural projection, source hygiene, registry and release routes.
- Kept the protocol separate from licensing, legal permission, automatic rights resolution, adoption claims and private ingestion ledgers.
- Repaired literal escaped line breaks introduced in the previous documentation integration.

## 2026-08-17 — Repository-wide public stamps

- Applied a compact Full ZIP distribution route and Credits & Attribution stamp across every tracked public text file in the repository.
- Added an idempotent repository stamp applicator and a CI validator so future Markdown, Python, YAML and JSON components inherit the same public contract.
- Preserved the permission boundary: public availability and attribution do not themselves grant reuse rights.
- Required registered portable fingerprints to refresh whenever the stamp changes canonical bytes.
