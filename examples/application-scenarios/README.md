# Hypothetical application scenarios

These fictional worked examples show how Moon Source could be applied to common context problems. They are explanation surfaces, not case studies, implementation reports or evidence of adoption.

> **Status:** hypothetical / fictional didactic scenarios. These examples illustrate how Moon Source could be applied to common context problems. They are not evidence of external adoption, implementation, measured impact or independent validation.

The recurring shape is deliberately small:

**understand → structure → validate → maintain**

Each scenario uses the same public contract:

1. identify the common problem;
2. explain why raw accumulation of context is insufficient;
3. read the field and assign authority;
4. choose the smallest useful public materialization;
5. define update and readback rules;
6. state what the example does not claim.
