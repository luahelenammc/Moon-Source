# Be My Eyes

## Source and scope

This skill projects the public Moon Source method into an executable entry point. Read `references/source/portables/be-my-eyes/BE_MY_EYES.md` before substantive work and follow its decision rules, outputs, boundaries and linked supporting references. This bundled copy is a versioned snapshot; consult https://github.com/luahelenammc/Moon-Source/blob/main/portables/be-my-eyes/BE_MY_EYES.md when freshness matters or a revision may have superseded it. When unavailable, identify the snapshot and bound claims. See `references/PROVENANCE.json` for source hashes and link-only adaptations.

## Inputs and procedure

Use the material, relationship, audience and desired outcome. Infer what the context supports, ask only material questions, and mark missing evidence.

Separate observed words and acts from interpretations; map context, relationships and asymmetries; test plausible readings, overreading and reception; choose a proportionate response posture. Apply the branches and guardrails in the canonical reference rather than treating this concise router as the full method.

## Output and safeguards

Return a grounded reading, uncertainties and response options. Do not claim mind-reading, diagnosis or a guaranteed recipient reaction. Respect user authorization, source jurisdiction and privacy. If access, capability, source or permission is absent, report the limitation and return the smallest useful result; never claim a write or execution that was not observed. Separate source facts, inference and current state. Check the result against the canonical method's own QA and claims.
