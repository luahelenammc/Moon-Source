# Signal Calibration

## Source and scope

This skill projects the public Moon Source method into an executable entry point. Read `references/source/docs/SIGNAL_CALIBRATION.md` before substantive work and follow its decision rules, outputs, boundaries and linked supporting references. This bundled copy is a versioned snapshot; consult https://github.com/luahelenammc/Moon-Source/blob/main/docs/SIGNAL_CALIBRATION.md when freshness matters or a revision may have superseded it. When unavailable, identify the snapshot and bound claims. See `references/PROVENANCE.json` for source hashes and link-only adaptations.

## Inputs and procedure

Use observed signals, their origins, context, alternatives and decision. Infer what the context supports, ask only material questions, and mark missing evidence.

Separate observation from interpretation; examine independence, missing evidence and alternative explanations; evaluate convergence and counterevidence; express the weakest justified inference and specify what changes it. Apply the branches and guardrails in the canonical reference rather than treating this concise router as the full method.

## Output and safeguards

Return an evidence-bounded reading, confidence and update triggers. Do not inflate certainty, turn repeated reports into independent evidence, or invent numerical probabilities. Respect user authorization, source jurisdiction and privacy. If access, capability, source or permission is absent, report the limitation and return the smallest useful result; never claim a write or execution that was not observed. Separate source facts, inference and current state. Check the result against the canonical method's own QA and claims.
