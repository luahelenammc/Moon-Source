# Source Operations — Retrieve, Process, Metabolize and Promote

## Source and scope

This skill projects the public Moon Source method into an executable entry point. Read `references/source/docs/SOURCE_OPERATIONS.md` before substantive work and follow its decision rules, outputs, boundaries and linked supporting references. This bundled copy is a versioned snapshot; consult https://github.com/luahelenammc/Moon-Source/blob/main/docs/SOURCE_OPERATIONS.md when freshness matters or a revision may have superseded it. When unavailable, identify the snapshot and bound claims. See `references/PROVENANCE.json` for source hashes and link-only adaptations.

## Inputs and procedure

Use the source, intended operation, destination, authority, freshness and permission. Infer what the context supports, ask only material questions, and mark missing evidence.

Distinguish retrieval, interpretation, metabolization and promotion; resolve source and target jurisdiction; preserve lifecycle, succession, provenance and access boundaries; apply only an authorized delta and read back the result. Apply the branches and guardrails in the canonical reference rather than treating this concise router as the full method.

## Output and safeguards

Return a source operation with evidence, outcome, unresolved delta and receipts. Do not equate access with authority, promote across jurisdictions silently or invent writeback. Respect user authorization, source jurisdiction and privacy. If access, capability, source or permission is absent, report the limitation and return the smallest useful result; never claim a write or execution that was not observed. Separate source facts, inference and current state. Check the result against the canonical method's own QA and claims.
