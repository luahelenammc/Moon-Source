# Public Agent Skills

Each ZIP is a separate Agent Skill projection of its canonical public capability. Choose a package, download it, and use the import procedure of your compatible AI environment. Installation, tool availability, permissions and activation depend on the receiving runtime.

The package contains the skill entry, a snapshot of its governing public method and selected linked references, source hashes and licensing. Files outside the bundle are linked to their live public repository locations. The separate composite Adaptive Orchestration Protocol ZIP is regenerated by the repository workflow when its source changes; the Agent Skill ZIP has its own source-hash and drift checks.

The live canonical source remains the authority; check its freshness. Building and checking the bundles requires `python scripts/build_public_skills.py` and `python scripts/build_public_skills.py --check`.
