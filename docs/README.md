# Moon Source documentation guide

This directory contains structural method bodies, public reading guides, technical integration notes and editorial contracts. It is a **navigation aid**, not a new capability registry. The [canonical capability registry](../registry/PUBLIC_CAPABILITIES.md) governs identity, version and authority. The [problem-first guide](PROBLEM_TO_METHOD.md) gives concrete starting situations.

| **Execute** | [Operational Devices](OPERATIONAL_DEVICES.md), [Operational Reliability](OPERATIONAL_RELIABILITY.md), [Failure Foundry](FAILURE_FOUNDRY.md) | [Adaptive Orchestration](../portables/adaptive-orchestration/README.md) |

These groups do not imply a compulsory pipeline or a new authority structure. [Architecture — Field to Form](../ARCHITECTURE.md) and the [AI Kernel](../MOON_SOURCE_AI_KERNEL.md) are cross-cutting architectural entry points, not additional public capabilities.
