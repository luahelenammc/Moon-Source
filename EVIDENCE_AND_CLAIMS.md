# Evidence and Claims

Moon Source is disclosed through existing evidence only. This repository organizes artifacts that already exist; it does not manufacture a case to justify the architecture.

## Evidence classes

| Class | Meaning |
|---|---|
| PUBLIC_ARTIFACT | A deliberately published portable or public-facing file can be inspected directly. |
| PUBLIC_REPOSITORY | A public repository or path exposes the claimed implementation or documentation. |
| INTERNAL_SOURCE_USED | A private or internal source informed a public-safe formulation, without making the internal body public. |
| IMPLEMENTED_BOUNDED | A bounded implementation exists, but the claim is limited to the observed slice. |
| TESTED_BOUNDED | A bounded test or verification supports a narrowly stated technical claim. |
| INCUBATING | The idea exists and is being developed, but is not presented as a finished public capability. |
| PLANNED | The work is intended but not yet implemented or released. |
| RESERVED | The material is intentionally withheld for privacy, security or intellectual-property reasons. |
| NOT_DEMONSTRATED | The available evidence does not establish the claim. |

## What the current public body supports

- Moon Source is a public context-architecture method and reference architecture. Evidence: PUBLIC_ARTIFACT, PUBLIC_REPOSITORY.
- Moon Source includes independently readable public portables for setup, adaptive structural grammar and Chat–Work routing. Evidence: PUBLIC_ARTIFACT.
- MSL 4.3 is the current public structural standard in this repository. Evidence: PUBLIC_ARTIFACT, INTERNAL_SOURCE_USED.
- The repository is a public versioning and reference body. Evidence: PUBLIC_REPOSITORY.
- The website is a human-facing public surface and the professional page is a separate professional context. Evidence: PUBLIC_REPOSITORY and public URLs.

## What the current public body does not establish

Public artifact is not adoption.

Internal use is not external validation.

A tested slice is not full runtime proof.

A materialized skill is not proven impact.

A repository is not product-market fit.

A reference architecture is not a universal standard.

This repository does not claim:

- validated enterprise deployment;
- external adoption;
- universal superiority over other context systems;
- a general software engine without corresponding public implementation evidence;
- automated cross-platform synchronization;
- native Personal Skills availability on every ChatGPT surface;
- full Citadel runtime proof;
- consciousness or autonomy;
- MSL 5.

## Claim discipline

Every new public claim should answer:

1. What artifact or source supports it?
2. What does that evidence actually demonstrate?
3. What remains outside the evidence?
4. Is the language stronger than the evidence?

If a claim cannot answer those questions, label it INCUBATING, PLANNED, RESERVED or NOT_DEMONSTRATED.
