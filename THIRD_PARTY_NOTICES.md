# Third-Party Notices

This file is the release-relevant third-party notice surface for Moon Source. It is intentionally narrower than [`docs/CREDITS_ATTRIBUTION_OPS.md`](docs/CREDITS_ATTRIBUTION_OPS.md), which records broader provenance and custody operations.

## Audit scope

The tracked public body was audited against its current files, Git history, existing lineage documentation, file references and dependency/configuration surface before this licensing ratification. The active public body contains no identified third-party code, copied image, embedded media or third-party text excerpt that is being silently relicensed as Moon-authored material.

The repository does contain references and links to external standards, products and documentation. A reference, citation, URL or product name is not by itself an incorporated third-party work. The referenced party's own terms remain applicable to material obtained from that party.

## Standard license texts

The repository includes the following standard legal texts verbatim for redistribution clarity:

- `LICENSES/Apache-2.0.txt` — Apache License 2.0, sourced from the Apache Software Foundation's canonical text: https://www.apache.org/licenses/LICENSE-2.0.txt
- `LICENSES/CC-BY-4.0.txt` — Creative Commons Attribution 4.0 International legal code, sourced from Creative Commons' canonical text: https://creativecommons.org/licenses/by/4.0/legalcode.en

These files are not relicensed as Moon-authored works. They govern the material to which their respective identifiers apply.

The repository also refers to GitHub, Creative Commons, SPDX and REUSE as infrastructure, standards or public reference sources. Their names, marks, documentation and services remain subject to their own terms. Moon Source does not claim ownership of them.

## When a new donor is incorporated

Before adding a copied snippet, image, dataset, template, excerpt or other material from outside Moon Source:

1. identify the source and rights holder where known;
2. identify the applicable license or permission;
3. check compatibility with the target file class;
4. preserve the upstream notice and required attribution;
5. add a file-level SPDX override or a specific entry here;
6. keep uncertain material explicitly exceptional rather than guessing.

Mere inspiration, general reference or independently recreated concepts should not be inflated into a false incorporated dependency. Material influence should remain recoverable through Credits & Attribution Ops when it is material.

## Current exception register

No active public source file currently requires a separate third-party license exception beyond the standard license texts listed above and the external references described in this notice. This register must be updated before a future release that incorporates donor material.
