# 🧭 Setup — Moon Source portable

**Build the smallest useful AI context setup for a person or project without turning context into a pile of everything.**

[▶️ Start here](MOON_SOURCE_SETUP.md#first-use) · [⬇️ Download package](../../downloads/moon-source-setup-3.1.zip) · [🌙 Moon Source](../../README.md)

## Use this when

- you want an AI to understand a person, project or recurring workflow more consistently;
- useful context exists across several places and needs proportionate routing;
- you are unsure whether the right answer is a lightweight setup, a persistent source or something deeper;
- you want context that stays legible instead of silently accumulating.

## What it does

Moon Source Setup is an adaptive context router. It helps determine the smallest useful setup for the field in front of you and can route toward persistent sources when that is actually warranted.

## What it does not do

It does not install a memory system, connector, background service or universal profile. Availability of a source or integration is separate from authority to use it.
