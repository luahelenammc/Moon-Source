# Connected Sources

A public portable for living-source continuity: reach the current source, resolve what it governs, act within permission and verify the resulting state.

[⬇️ **Download Connected Sources package (.zip)**](../../downloads/connected-sources-1.1-public.zip)

## Start here

Paste `CONNECTED_SOURCES.md` into an AI conversation and say:

```text
Use Connected Sources for this task.
```

The portable is independently readable. It works without a connector in Standalone Mode and becomes more capable when the current AI surface can resolve a persistent source.

## Four modes

- **Standalone Mode:** work from material actually supplied; do not imply cross-session current-source continuity.
- **Connected Read Mode:** reread a reachable source; do not infer mutation permission.
- **Living Source Mode:** perform an authorized bounded write and read it back before accepting the result.
- **Federated Source Mode:** let different substrates govern different facets, such as semantic documents, executable code and CI evidence.

Google Drive is the recommended ChatGPT document-source reference for durable living sources. GitHub complements it for executable and repository state. Neither is mandatory, and neither is a universal source of truth.
