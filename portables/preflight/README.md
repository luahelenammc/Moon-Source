# 🛫 Preflight

**Turn messy, conversational or self-correcting human expression into the faithful task the person actually meant before execution begins.**

[▶️ Start here](PREFLIGHT_V2.md#first-use) · [⬇️ Download package](../../downloads/preflight-v2.zip) · [🌙 Moon Source](../../README.md)

## Use this when

- the request mixes context, corrections, examples and the actual ask;
- literal execution would likely miss the intended outcome;
- the person knows what they do **not** want more clearly than how to phrase what they do want;
- a consequential task needs its real intent reconstructed before heavier guardrails activate.

## What it does

Preflight reconstructs intended meaning, desired outcome and important constraints in ordinary language, then hands execution the smallest faithful working task.

## What it does not do

It is not mind-reading, a mandatory questionnaire or an excuse to over-architect a clear request. Source, authority, provenance and mutation checks enter only when the reconstructed task materially needs them.
