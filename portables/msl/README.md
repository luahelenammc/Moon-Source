# 🧱 Moon Source Language

The public portable edition of Moon Source Language, currently version **4.3**, the adaptive structural grammar used to choose proportionate form for context work.

[⬇️ **Download Moon Source Language package (.zip)**](https://github.com/luahelenammc/Moon-Source/raw/refs/heads/main/downloads/moon-source-language-4.3.zip)

## First use

Moon Source Language (MSL) helps a person or AI decide what form a piece of context has earned: a source, handoff, packet, procedure, protocol, registry or archive. It is a method and grammar, not a parser, runtime or universal standard, and you do not need to learn the whole grammar before using it.

For repository-wide orientation, return to [Moon Source first use](../../README.md#first-use).

### Nothing is installed

Reading or pasting [`MSL_4_3.md`](MSL_4_3.md) does not install a runtime, memory system, synchronization service or governance engine. MSL can be applied directly to material you provide. The canonical body is the semantic authority; this README is the practical entry point.

### Say this first

```text
Use Moon Source Language for this material.
First identify what the material needs to do, who must rely on it,
and what must remain uncertain. Choose the smallest proportionate form.
Do not introduce a maximal schema unless the material earns it.

Material: [paste or attach the notes, facts or draft]
```

A useful starting order is: field before form, facts before interpretation, responsibility before decoration, and decision before operation. The form should follow maturity, authority, reuse and operational need.

### What happens next

The AI may recommend a short handoff, decision record, source note, procedure, protocol, registry or archive. It should preserve unresolved facts as explicit unknowns and avoid freezing exploratory material into rigid structure merely because a schema is available.

### Minimal example

Raw notes:

- Jo owns the rollout.
- The team agreed to start next week.
- The deadline is still missing.
- The source link has not been checked.

A proportionate MSL result is a short handoff or decision record that preserves Jo's responsibility, the agreed direction and two explicit unknowns. It is not yet a registry or a full operational protocol.

### Manual actions and unavailable capabilities

You may need to choose the destination, provide missing facts, approve the form, save it in the right source or run a later freshness check. MSL does not store, synchronize, publish or govern the material by itself. The AI should not invent a source authority, owner, deadline or decision merely to complete a template.

### What this portable does not claim

- It is not a programming-language runtime or universal data standard.
- It does not automatically create durable memory or synchronized sources.
- It does not prove that a form is governed merely because it looks formal.
- It does not make a reason to formalize disappear.
- It does not replace human authority, provenance or freshness checks.

### Troubleshooting

If the result is overbuilt, say:

```text
Use the smallest MSL form that can carry the current responsibility.
Preserve unresolved facts as explicit unknowns.
Do not create a maximal schema, registry or protocol yet.
```

If the material is too thin to formalize, keep it as a bounded working note and identify the next fact or decision that would earn a stronger form.
