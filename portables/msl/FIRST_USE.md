# Moon Source Language — First-Use Guide

_Read this before using the MSL portable._

## What this is for

Moon Source Language (MSL) is an adaptive structural grammar for choosing a proportionate form for context work: a source, handoff, packet, procedure, protocol, registry or archive.

It helps answer “what form is earned by this material?” It does not require every situation to become a large schema.

## Nothing is installed

Reading `MSL_4_3.md` does not install a parser, runtime, universal standard, memory system or governance engine. MSL is a method and grammar that an AI or person can apply.

Use the canonical body [MSL_4_3.md](MSL_4_3.md). This [root FIRST_USE.md](../../FIRST_USE.md) handles onboarding; the canonical body remains the semantic authority.

## Say this first

Provide the canonical file and say:

~~~text
Use Moon Source Language for this material.
First identify what the material needs to do, who must rely on it,
and what must remain uncertain. Choose the smallest proportionate form.
Do not introduce a maximal schema unless the material earns it.

Material: [paste or attach the notes, facts or draft]
~~~

A useful starting sequence is: identify the field, separate facts from interpretation, identify responsibility and decision, then choose the smallest form that can carry the work.

## What happens next

The AI may recommend a short handoff, decision record, source note, procedure, protocol, registry or archive. The form should follow maturity, authority, reuse and operational need. A material that is still exploratory should not be frozen into a rigid structure merely because a schema is available.

## Minimal example

Raw notes:

- Jo owns the rollout.
- The team agreed to start next week.
- The deadline is still missing.
- The source link has not been checked.

A proportionate MSL result is a short handoff or decision record that preserves Jo's responsibility, the agreed direction and two explicit unknowns. It is not yet a registry or a full operational protocol.

## Manual actions and unavailable capabilities

You may need to choose the destination, provide missing facts, approve the form, save it in the right source or run a later freshness check. MSL does not store, synchronize, publish or govern the material by itself.

The AI should not invent a source authority, owner, deadline or decision merely to complete a template.

## What this portable does not claim

- It is not a programming language runtime or universal data standard.
- It does not automatically create durable memory or synchronized sources.
- It does not prove that a form is governed merely because it looks formal.
- It does not make a reason to formalize disappear.
- It does not replace human authority, provenance or freshness checks.

## Troubleshooting

If the result is overbuilt, say:

~~~text
Use the smallest MSL form that can carry the current responsibility.
Preserve unresolved facts as explicit unknowns.
Do not create a maximal schema, registry or protocol yet.
~~~

If the material is too thin to formalize, keep it as a bounded working note and identify the next fact or decision that would earn a stronger form.
