# Project MRI roadmap

## Current — public reference build

- deterministic bounded scanner;
- evidence-backed diagnostics;
- human review ledger;
- fixed evaluation and negative fixture;
- local demo, reset and exports;
- clean open-source packaging and CI.

## Next, only with real use

- repository-aware adapters with explicit scope;
- a persistent review ledger with an auditable source-of-record model;
- measured human agreement on a consented corpus;
- optional provider-backed extraction or document operation when it is load-bearing and verifiable.

## Deliberately deferred

- autonomous mutation;
- silent authority promotion;
- broad private-repository crawling;
- multi-tenant hosting;
- compliance certification;
- GPU integration without a real workload.
