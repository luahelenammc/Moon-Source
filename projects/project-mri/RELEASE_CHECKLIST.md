# Competition-ready release checklist

## Build

- [x] Python 3.10+ source-run path documented.
- [x] Package metadata and CLI entrypoint present.
- [x] Runtime dependency surface is standard-library-only.
- [x] Unit tests cover core, negative, ZIP and symlink boundaries.
- [x] Northstar golden eval is reproducible.
- [x] Local web demo has health, reset and report routes.

## Public boundary

- [x] Synthetic fixtures only.
- [x] No credentials, secret prompts or private source material.
- [x] Predecessor-era material removed from the active surface and quarantined in archive history.
- [x] Optional provider adapter is not on the critical demo path.
- [x] Claim map distinguishes observation, inference and prohibited claims.

## Publication

- [x] Apache-2.0 code license and CC BY 4.0 documentation map prepared.
- [x] Author and AI-assisted development attribution visible.
- [x] Contribution, security and roadmap guidance present.
- [ ] Human completes InfraJam registration and accepts any binding terms.
- [ ] Human completes the final competition submission if desired.

## Demo

- [x] One-command demo scan.
- [x] Resettable review state.
- [x] Seven-frame capture plan and fallback visuals.
- [x] Two-to-three-minute judge script.
- [ ] Capture and attach the final screenshots/video on the competition surface.

## Swift Compute

- [x] No false live-integration claim.
- [ ] Optional provider/runtime path only if registration credentials become available and a load-bearing operation is verified.
