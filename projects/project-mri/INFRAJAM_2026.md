# InfraJam 2026 — opportunity and release boundary

**Official source checked:** 2026-09-14 · <https://infrajam.swiftcompute.ai/>

## Current official surface

The landing page describes InfraJam 2026 as a Swift Compute hackathon running September 19–20, 2026, with virtual and in-person participation, free entry, access to GPU cloud resources for registered participants, and a US$2,000 prize pool. It says virtual participants can fully participate online with equal access to prizes, allows solo participation and describes teams of up to four.

The published judging dimensions are innovation, technical complexity, usefulness and presentation. The listed tracks include Open Source, Developer Experience, AI/ML Infrastructure, Cloud Native, Security & Privacy and Wild Card.

## Selected route

**Primary track: Open Source.** MRI is a new, executable reference implementation of governed-context infrastructure. It can be cloned, tested, inspected and extended without requiring private Moon sources. Developer Experience is a demonstrated secondary value through the CLI, resettable demo and machine-readable output.

Rejected as primary routes:

- **Developer Experience:** genuine secondary fit, but the current body is more fundamentally a source-governance instrument than a GPU-workflow productivity tool.
- **AI/ML Infrastructure:** not selected because no model deployment, training, orchestration or meaningful GPU workload is part of the verified build.
- **Cloud Native / Security & Privacy / Wild Card:** no current implementation or rule fit justifies them without distortion.

## Rule gaps and external gates

The current public page does not expose a separate registration cutoff, final submission deadline, project form, source-code requirement, license requirement, IP transfer term, track-specific constraint, pre-existing-code rule or requirement to use Swift Compute. It does expose the registration form and a plain good-faith participation statement. These absences are recorded as unverified, not as permissions.

Registration, acceptance of any binding terms, receipt of credentials and final submission remain human actions. This repository is prepared before those actions and makes no claim that Moon is registered, accepted, a finalist or a winner.

## Swift Compute status

**Not integrated.** The deterministic local path is complete and useful without a GPU. A provider path may be added only after access exists and a live operation materially improves the workflow. No benchmark or sponsor-integration claim is made here.
